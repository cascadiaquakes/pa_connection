About

P&A Connections Viewer

What this tool is for

This viewer is an interactive map of organizations and relationships in the P&A network. It is intended to help users explore how agencies, partners, roles, and connections relate to each other, filter the graph for specific questions, and export views for discussion or analysis.

The tool is a prototype for exploration and sensemaking. It should be used as a reference aid alongside source materials and local knowledge, not as a formal system of record.

About the data

The dataset is made from public information gathered by our team. Because public information can change, check the last edit date for each organization or relationship to understand how recently that item was reviewed and whether newer information may need to be confirmed.
