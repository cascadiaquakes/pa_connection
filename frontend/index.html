About

Cascadia Connections Dashboard

Welcome to the Cascadia Connections Dashboard

This viewer is an interactive directory of entities involved in earthquake hazard research and resilience efforts related to Cascadia (i.e. the Pacific Northwest region bordered by the Cascadia Subduction Zone, extending from British Columbia through to Northern California). Through visual categorization and identification of roles of the organizations and communities involved, it is intended to help users understand the seismic resilience ecosystem, and to promote partnerships and collaborative projects.

The viewer also has functionality to display relationships between organizations and is built around open-source graphing software that allows statistical network analysis based on available relationship data.

About the Viewer

In the default view, entities are mapped by organizational category (columns) and geographic location of operation (rows). Definitions are available by hovering your cursor over the column and row headers.

Menu tabs on the top left of the display include:

  • Controls maintains a view of the whole ecosystem map, with entities highlighted or greyed out according to the checkbox parameters chosen under the “Selection” headings on the left sidebar. Color preferences and graph view settings can also be adjusted under this tab.
  • Filters allows entities, organizational categories, and geographic locations to be removed from or included in the main map using the checkboxes under “Node filters.”
  • Info provides metadata for a selected entity. Select “More” to open an expanded data window for that entity.
  • Export allows you to download the entire dataset as a JSON file or generate a PNG image of the current dashboard view.
  • Search produces a list of entities containing the chosen search term in their title or metadata.

About the Data

Entities have been included in the dashboard based on exploratory research by CRESCENT staff into who’s who in the seismic resilience ecosystem. Initial directory metadata were populated by compiling public information provided by partners and web searches, then summarized with assistance from generative AI. Relationship data are incomplete and are included to demonstrate network analysis potential, subject to further research. All data are provisional until verified or submitted by an official representative of an entity.

Except where otherwise noted, the P&A Directory database compilation and original content created by CRESCENT are licensed under the Creative Commons Attribution 4.0 International License.

Please provide or update directory information for your entity via our data intake form. Submitted data will be acknowledged in the metadata for the associated entity, including a timestamp for when information was last updated.
